# 编辑音乐服务器与歌曲信息

适用于 preview.17-rc.1 及以后。安装同一变体的签名 APK 覆盖升级，不要先卸载。普通播放无需升级 NAS 或配套资料管理后台。

## 修改已有服务器

打开 **设置 → 音乐服务器 · 切换与退出 → 服务器更多菜单 → 编辑连接**。新增、编辑和首次连接使用同一全屏表单。

- **名称**仅影响显示，可离线修改，不暂停音乐。
- **地址**填写 Navidrome / Subsonic 服务的基础入口，可包含端口与服务路径，不要填写 NAS 管理页或手工追加 `/rest`。公网使用 HTTPS。
- **账户／密码**：相同地址和账户、仍有凭据时，密码留空保留原凭据；地址或账户变更、退出后重新登录必须填写密码。原密码不会回显。
- **测试连接**只测试当前输入，不保存、不切换。测试成功不等于已经保存，也不证明两个地址属于同一曲库。
- **保存**提交配置；新增或非当前连接可选“保存并切换”。另一服务器／账户另存后，原连接仍保留。

地址变化时，明确选择：

| 选择 | 数据处理 |
|---|---|
| 同一 NAS、同一账户换地址 | 保留原账户内部标识、下载、曲库、队列、歌单快照、歌词及本地记录 |
| 另一台服务器／另一账户 | 创建独立连接；原连接和数据保留，不合并 |

保留数据前需确认音乐服务、账户及曲库标识未重建。应用会只读抽查最多三首歌曲的 ID、标题和时长：内容明显不同时拒绝保留，要求另存；无法核实时明确提示，只有再次确认才允许保留。少量抽查不是整个曲库身份的绝对证明。已有相同地址和账户时，返回使用已有连接。

测试、验证失败不覆盖旧连接，播放继续。修改当前连接的地址或凭据并保存时，先保存进度、暂停播放与下载、取消旧请求，再提交新配置并重新连接；完成后保持暂停。修改非当前连接不打断当前播放。原下载无需重下，仍可播放；后续网络请求使用新地址。名字或密码修改不强制全库更新，仍按已有更新周期执行。

保存使用加密恢复记录；提交期间不接受重复操作，应用中断后完成已验证的提交。验证阶段可取消，关闭表单清除密码输入。配套曲库管理后台的地址独立配置，不自动改写。

## 在表单里看错误

字段格式问题显示在字段下方并定位；认证、域名、连接、超时、证书或服务响应问题显示在表单底部，键盘打开时也可见。失败保留输入，可以修改后重试；不必关闭表单找提示。修改任一连接字段会使旧测试结果失效，迟到的请求结果不会覆盖新输入。证书错误不提供跳过校验按钮。

若配置已保存但切换／加载失败，页面明确标示已保存，返回服务器列表重试切换即可，避免重复新增。

## 从歌曲信息打开歌手或专辑

播放页底部点 **歌曲信息**。歌名与歌手文字仅展示，避免误触跳转。面板包含原始演唱署名、逐位演唱者、个人／共享整理后的作品归属、专辑、曲风、年份、时长、曲目／碟号与音乐来源；缺失信息显示“未提供”。

只有能定位到当前曲库的歌手／专辑显示箭头。同名歌手按 ID 区分，同名专辑优先按专辑 ID／现有发行分组定位；不联网补资料。原始演唱者页保留参与作品，不因个人归属整理而丢失合唱作品。

点击箭头会关闭面板、收起播放器并立即显示详情。继续进入专辑可逐层返回；退出这次详情浏览后回到播放页，保留唱片／歌词模式及歌词浏览状态，再收起播放器回到原页面。后台切歌时面板仍绑定打开时的歌曲，返回播放器显示实际当前歌曲。切换账户清除面板和返回路径。

“加入歌单”“修改作品归属”“纠正歌曲信息”在面板内保留。打开信息和详情不发送播放、下载或队列重建命令。

验证记录见 [TESTING.md](../TESTING.md)。厂商真机、TalkBack 实际朗读和真实 NAS 的改址仍需使用者确认；生成服务的自动测试不替代这些结果。
