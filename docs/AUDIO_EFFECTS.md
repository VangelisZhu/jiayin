# 音效与耳机（preview.15）

在 **我的 → 设置 → 音效与耳机**，或播放页右上角的独立音效图标进入。新装和升级默认关闭；开启后记住选择。只作用于家音本机音频，不修改 NAS 文件，不上传音乐，不需要升级后台。

## 快速使用

1. 开启总开关，保留“自动”策略。明确的曲风标签选择对应音色，未知或冲突使用“温暖饱满”。页面显示当前真正生效的音色、依据、输出和状态。
2. 如果希望所有歌曲保持一样的音色，选择“固定”及预设。固定模式暂不使用曲风和单曲指定。
3. 耳机默认“自然耐听”，以轻度交叉馈送缓和左右分离；可选择“轻度沉浸”扩大立体声宽度，或关闭空间处理。默认空间强度 25%，音色强度 50%。
4. 用“原声对比”临时旁路新增处理，再点一次恢复；关闭此页面自动结束对比。总开关关闭旁路全部新增处理并保留配置。
5. “此歌曲的音效设置”按当前服务器账户与歌曲 ID 保存，提供“恢复自动”。不会提交管理员审核或共享给其他用户。

## 预设与规则

| 音色 | 自动标签示例 | 听感方向 |
|---|---|---|
| 温暖饱满 | 未识别、冲突 | 轻补低频、减少中低频堆积和尖锐感 |
| 流行人声 | Pop、华语流行、J-Pop、K-Pop | 人声清楚、伴奏保留厚度 |
| 节奏低频 | Hip-Hop、Rap、R&B、Electronic、Dance | 低频弹性 |
| 摇滚层次 | Rock、Metal、Punk | 鼓和吉他的层次 |
| 原声自然 | Acoustic、Folk、Jazz | 克制修饰 |
| 均衡原声 | Classical、古典 | 平直均衡；空间效果仍独立 |

仅匹配明确标签及内置别名，不根据姓名、国籍或文件名猜测，也不扫描音频分析风格。多个已识别标签属于不同预设时使用默认；只有一个已识别预设时使用该预设。自动模式顺序为“此歌曲指定 → 曲风 → 默认”。不同版本、不同 ID 的同名歌曲分别保存。

设备偏好分耳机、手机扬声器、其他本地输出保存，自动与固定、默认预设及两种强度均独立；总开关全设备共享。编辑非当前输出时会说明“切换到此输出后应用”。真实路由来自播放 AudioTrack，而非已连接设备名单，因此蓝牙手表不触发耳机设置。未播放时可先编辑耳机偏好。

“恢复默认”关闭总开关，并恢复正在编辑的输出偏好；保留其他输出与歌曲指定。退出音乐账户保留单曲规则，移除该账户同时删除规则。

## 音频与设备边界

- 手机本地软件 PCM 处理，使用浮点中间计算，最后一次转成整数输出；不承诺位完美或高位深直出。24 位音源可解码播放，但本轮音效链输出为标准 16 位 PCM。
- 关闭音效保持相同播放器、音频路径、队列和媒体会话，不以重启播放来切换输出格式。手动调整约 200ms、自动换预设约 500ms 平滑过渡；快速调整合并至最新目标，正在进行的有界过渡完成后接入最新目标。
- 每段均衡最大增减 3dB，额外预留组合增益空间并限制输出峰值，不自动提高系统音量、不开启 ReplayGain、不进行持续动态压缩。因此部分效果会略低于原声响度；更响不等于音质更好。
- 自然模式与沉浸模式互斥。沉浸模式保留居中人声，低频不扩宽，不加长混响。单声道不制造空间效果，多声道全部绕过新增处理并标明原因。
- 只支持本机播放。远端设备自行获取音频时，手机处理器不在音频路径中。USB 通用音频设备无法确认是耳机时归为“其他本地输出”，可以手动设置该类偏好。
- 本机软件路径请求系统不要再执行空间化，避免重复处理；厂商、耳机 App 仍可能另加音效。家音不会改动系统声音配置，提供设置入口供自行比较。
- 立体声空间处理不是 Dolby Atmos、多声道原始环绕或头部追踪；本轮不包含耳机型号校准、AutoEQ 数据库或 HRTF。
- 音效不改变耳机断开暂停、重连等待手动播放、视频打断、睡眠定时及账户切换规则。异常时旁路并提示，不反复重试或自动恢复出声。

## 实现与试听

`AudioEffectResolver` 负责纯本地选型，`AudioEffectStore` 保存设备与账户规则，当前播放服务持有 `AudioEffectController` 与 `JiayinAudioEffectProcessor`。滤波系数及处理缓冲在后台准备，音频线程不读数据库、网络或文件；账户生命周期结束会注销路由监听并取消准备任务。

验收包括纯信号频响、峰值、声道与静音、相同 PCM 路径关闭时逐样本一致、100 次参数切换，以及真实 Media3 24 位立体声输入后的处理状态、队列进度、通知 token 和下载计数。具体已验证与尚未验证的项目见 [测试记录](../TESTING.md)。

试听时尽量比较相近响度，重点听低频是否浑浊、人声是否后退、高频是否刺耳。音效偏好取决于录音和耳机；OPPO 实际耳机试听、系统音效叠加与两小时耗电需要真机确认。
