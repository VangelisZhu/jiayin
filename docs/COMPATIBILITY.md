# 直板手机布局与兼容性

## 支持边界

家音要求 Android 7.0 / API 24 或以上。布局依据应用实际可用宽高、系统字体和安全区域调整，不按品牌或物理像素硬编码。不包含折叠屏、平板的专属布局。

- 窄屏使用较小的页面边距；搜索输入、按钮和迷你播放器支持大字号。
- 普通竖屏的专辑以两列为主，宽屏按最小卡片宽度增加列数，大字号可以单列显示。
- 播放页先测量控制区，再分配唱片空间；短屏提供滚动，宽度足够的横屏使用左右布局。
- 列表标题与筛选在窗口很矮时可滚出视口，仍为列表保留可操作区域。
- 字母索引在短窗口优先显示有内容的字母；“字母”按钮打开可滚动的大按钮选择器。
- 搜索键盘占用后剩余高度不足 240dp 时暂时收起迷你播放器，收起键盘即恢复，播放不中断。
- 极矮窗口采用 56dp 高的图标导航，保留“首页／曲库／搜索／我的”的无障碍名称；窗口恢复高度后重新显示文字标签。
- 搜索键盘、状态栏、显示缺口与系统导航区域分别处理，避免重复添加间距。
- 改变窗口或字体不应重建队列、启动下载、切换账户或丢失页面状态。

## 验证等级

“模拟器尺寸通过”只说明对应 Android 环境的布局与交互通过，不代表厂商系统的后台、蓝牙、锁屏和音频焦点已经验证。具体运行结果见 [TESTING.md](../TESTING.md)。

| 品牌／系统 | 计划覆盖的直板系列 | 真机状态 |
|---|---|---|
| OPPO／一加，ColorOS | Find X、Reno、A／K、一加数字／Ace | 待验证 |
| 小米／Redmi，HyperOS | 数字、Ultra、Redmi K／Note | 待验证 |
| vivo／iQOO，OriginOS | X、S、Y、iQOO 数字／Neo | 待验证 |
| 三星，One UI | Galaxy S／S Ultra、A | 待验证 |
| 华为，支持 Android APK 的系统 | Mate、P／Pura、nova，需注明实际系统 | 待验证 |
| 荣耀及其他 Android | Magic、数字系列等 | 待验证 |

HarmonyOS 5 及以上的卓易通等运行环境单列测试，不等同 Android 原生兼容性；本项目没有发布原生鸿蒙应用。能否安装需以对应运行环境的实际支持为准。

## 报告问题

请提供机型、Android／系统版本、家音版本、横竖屏、字号／显示缩放、手势或三键导航，以及可复现操作。截图请遮挡服务器地址、账户和个人曲库信息。不要提交密码或认证链接。

## 开发验证

`AdaptiveUiTest` 使用本地生成的音乐与歌词，通过真实触摸检查播放、歌词、字母选择器、文件夹、搜索键盘、下载管理及服务器表单。断言页面操作没有改变暂停的队列或新增下载。

测试尺寸使用 dp；通过 `adb shell wm size` 和 `wm density` 设置模拟窗口后运行：

```sh
./gradlew connectedDegoogledDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.eddyizm.tempus.jiayin.AdaptiveUiTest
```

运行后必须恢复显示、字号、主题、导航方式和显示缺口设置。所有测试仅使用生成数据。
