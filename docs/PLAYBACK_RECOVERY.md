# 系统进度条与视频恢复（preview.16 候选版）

## 系统进度条

系统媒体面板与家音使用同一个绝对播放时间和跳转通道。原始流依据解码器实际可定位能力提供拖动，转码流通过 OpenSubsonic timeOffset 从指定时间续接；下载文件离线可定位。播放中拖动后继续，暂停中拖动仍暂停，连续拖动以最后目标为准。

系统控件是否允许拖动仍取决于系统实现。候选包已经包含平台 MediaController 与 Media3 控制器的测试；OPPO 控制中心必须另行真机检查，不能仅以 App 内拖动成功作为通过。

## 标准恢复

设置 → 播放与恢复 → “被视频打断后自动恢复”。保留原设置，新装默认关闭。原本播放中的音乐被短暂焦点中断后，收到系统归还才恢复；主动暂停、耳机断开、睡眠定时和切换账户会取消本次恢复资格。返回家音仍可按原规则续播，但后台重新连接播放服务不算用户返回。

永久失去音频焦点不保证收到归还事件，部分视频 App 暂停后仍保留焦点。

## 可选 B站恢复兼容

1. 开启“视频恢复兼容模式 · B站”，阅读说明；确认后同时开启自动恢复。
2. 按系统提示授予“通知使用权”。权限范围由 Android 定义；家音代码不读取通知正文，仅访问媒体会话的播放状态，不保存标题和内容、不上传。
3. 播放音乐，再进入 B站播放视频，暂停视频后观察是否原位续播。
4. 只有先观察到可明确关联的 B站本地媒体会话正在播放，随后同一会话明确暂停或停止并稳定 1 秒，才尝试一次恢复。焦点请求失败不会持续抢占。
5. 会话消失、状态未知、缓冲、其他媒体仍活跃、权限断开或系统禁止后台恢复时不会猜测视频已结束。兼容模式只适配 B站标准客户端的媒体会话；小红书保留标准焦点逻辑。

设置页会显示监听状态。若 B站版本不提供可靠媒体状态，无法保证停留在 B站内暂停后恢复；“返回家音可以恢复”不等同于这个场景已经修好。没有授权也能正常播放及使用标准恢复。关闭兼容开关会停止媒体会话监听，可另外在系统撤销通知使用权。

## 如何提交诊断

复现后打开设置 → 播放恢复诊断 → 复制诊断。记录仅保留当前播放服务最近 150 条焦点、暂停原因和恢复结果；关闭服务／切换账户不保留跨会话恢复资格。不含 NAS 地址、账户、音乐或视频标题。请另外注明 OPPO 型号、ColorOS 版本、AirPods 型号和 B站版本。

诊断中的 `resume=focus-gain` 是标准恢复，`resume=video-paused` 是兼容恢复，`resume=foreground` 是用户返回；`focus-denied` / `blocked-background` 表示系统未允许恢复。该记录不能证明耳机实际听感，需要真机试听。

本候选版不会启动 NAS 扫描，不需要后台升级，不改变原签名和账户数据。
