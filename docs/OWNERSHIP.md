# 作品归属整理（preview.14）

把合唱组合分组中的作品归入主要歌手，或建立个人浏览分组。原有演唱署名、专辑歌手、音乐文件、歌单与下载身份分别保留。

## 手机操作

1. 歌手主页点击“整理作品归属”，默认勾选当前组的现有歌曲，可以取消部分歌曲。单首操作从歌曲菜单“修改作品归属”进入。
2. 搜索并选择目标歌手，也可输入名称建立分组。检查歌曲清单和归属变化。
3. “保存个人整理”立即保存到当前手机的音乐账户，离线也可使用，不自动上传。
4. 希望家庭共享时，另外选择“预览并提交共享审核”，核对服务器预览后点“提交管理员审核”。不要求先保存个人整理。
5. “我的 → 作品归属 · 个人整理与申请”可恢复默认、查看申请明细、继续提交草稿、撤回未处理申请和刷新共享结果。

整组操作只包含确认时勾选的现有歌曲，不自动扩展到今后新增作品。不同歌曲 ID 分别处理；同名不同歌手 ID 不会合并，也不会按斜线或 `&` 自动拆分歌手名。

## 个人设置与共享结果

生效顺序：个人明确归属 → 管理员发布的共享归属 → 服务器原始演唱者归组。

- 个人设置按服务器及账户隔离，重新同步曲库后保留。本轮不提供个人整理的跨设备云同步。
- “恢复默认”先显示将采用的归属，确认后清除个人设置；共享设置不存在时采用原始演唱者。
- 其他用户的共享更新不覆盖自己的个人整理。个人页面显示不同的共享归属，可主动恢复默认。
- 自己提交的个人设置获批且此后没有更改时，转为跟随共享；提交后再次编辑的个人设置保留。
- 空的来源分组从歌手列表隐藏，已有收藏、地区、类型、排序名不会自动转移。原始演唱者仍可在歌曲菜单查看并浏览演唱作品。
- 搜索保留原始署名，并索引整理后的归属；推荐使用完整演唱者及整理归属共同约束，减少相同主要歌手连续出现。

播放页歌手入口使用当前作品归属。整理会刷新歌手列表、数量、字母索引和搜索范围，不重装正在播放的队列。

## 管理后台

共享功能需要配套后台 preview.14，并在 App 的“设置 → 资料纠正 · 账户权限与申请”连接同一音乐服务器。管理员先批准成员加入；只读成员可以获取共享结果，申请及直接修改成员都需要单独提交本类审核。

后台“资料纠正与审核”新增“作品归属审核”，显示原归属、目标歌手、歌曲清单与完整演唱署名。支持全部／部分批准、拒绝说明和撤销发布。此类操作只更新后台归属数据库，不调用文件写入或 Navidrome 扫描，也不等待歌曲播放结束。

共享范围是连接此后台且有歌曲访问权限的家音客户端，不改变 Navidrome 网页或其他音乐播放器。原有标签写入仍通过“资料纠正”流程单独审核执行。

相同歌曲的共享归属、文件绑定或相关资料发生变化时，申请标为冲突，需重新核对。被后续修改的发布不能直接撤销。客户端使用独立增量接口获取共享归属，不等待 30 天全库更新。后台暂不可达时保留已缓存的结果；旧后台显示升级说明，个人整理仍可使用。

## 升级与恢复

App 使用原包名和签名覆盖安装。新数据使用账户隔离的独立记录；批量保存和增量游标一起提交，继续使用分块存储。完整曲库更新后重新核对共享绑定；服务器歌曲 ID 被关联到其他文件时撤销旧共享归属，不按名称迁移。

后台升级保留现有 `/data` 挂载及原配置。备份管理数据后，使用新源码在 `manager` 目录执行：

```sh
docker compose build manager
docker compose up -d manager
```

使用群晖 Container Manager 或威联通 Container Station 时，更新原项目的镜像并重新创建容器，继续挂载原音乐目录和独立管理数据目录。新接口创建独立归属记录，保留原审核记录。

更换后台实例会重新获取共享归属，个人整理保留。管理员撤销发布后，联网刷新可获取恢复结果；有个人设置的设备继续采用个人设置。
